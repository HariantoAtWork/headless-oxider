# Add POST /pdf endpoint

Add `POST /pdf` backed by CDP `Page.printToPDF` (new `src/pdf.rs` plus wiring in
`main.rs` and `worker.rs`), using the same request body as headless-playwright
and returning raw `application/pdf` so CV Save as PDF can fail over between
Chromium backends. README notes that callers may pass a headless-tunnel
Chromium-facing URL. Also fix the release build by constructing the CDP
`Headers` value via serde_json instead of the non-existent `From<HashMap>` impl.
